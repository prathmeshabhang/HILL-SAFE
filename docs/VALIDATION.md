## 1. Validation Methodology & Principles

To prevent optimistic overfitting and ensure operational realism in mountainous terrain:
1. **Zero Data Fabrication**: All reported metrics are generated by code from automated test scripts in the repository.
2. **Stratified Holdout Splits**: Machine learning models evaluate on independent holdout test partitions ($20\%$) stratified by target disaster class (`random_state=42`).
3. **Probability Calibration**: Disaster classification models apply isotonic probability calibration evaluated via Brier score loss ($< 0.10$).
4. **Control Site Verification**: Natural dam and hazard detection algorithms are evaluated against known positive event sites (Sainj-Beas landslide dam) AND known negative control sites (Pandoh Dam, Larji Barrage) to verify false-positive rejection.
5. **Continuous Regression Testing**: 15 test suites encompassing 94 automated tests are executed prior to every milestone release.

## 4. Disaster Metric Standards

For all disaster prediction models in FLOODY SHIELD, evaluation avoids misleading raw accuracy (which is skewed by negative class dominance in rare events) and reports:
- **Precision**: Minimizes false alarms that cause economic disruption and alert fatigue.
- **Recall (Sensitivity)**: Minimizes missed catastrophic events that cause loss of life.
- **F1-Score / PR-AUC**: Balances precision and recall across rare disaster holdouts.
- **Brier Score Loss**: Evaluates probability calibration ($\text{Brier} = \frac{1}{N} \sum (p_i - y_i)^2$). Values $< 0.10$ demonstrate that a $70\%$ risk output corresponds to an authentic $70\%$ historical frequency.
- **ROC-AUC**: Evaluates discrimination ability across varying decision thresholds.

## 5. Spatial Holdout Validation — Scientific Validation Package

### 5.1 Methodology

To prevent spatial auto-correlation leakage (where randomly selected test pixels are adjacent to training pixels and share terrain features), the FLOODY SHIELD scientific validation package implements **latitude-block spatial holdout**:

`
ml/validation/spatial_split.py  →  create_spatial_block_holdout()
`

- **Partition**: Northernmost 20% of latitude range designated as test; southernmost 80% as train.
- **Buffer zone**: 0.01° (~1.1 km) excluded between train and test boundaries.
- **Guarantee**: Zero train/test spatial overlap verified by set intersection test.

### 5.2 Event & Temporal Holdout

`
ml/validation/event_split.py  →  create_event_holdout(), create_temporal_holdout()
`

When discrete storm-event identifiers or timestamps are absent, these functions explicitly flag:

`
VALIDATION NOT POSSIBLE WITH CURRENT DATA: No discrete historical event column found.
`

This is the correct scientific response. The system does not invent a synthetic validation split.

## 6. M7 Distribution Analysis — Saturation Investigation

### 6.1 Problem Identified

During spatial inference on the Upper Beas July 2023 scene, Model M7 reported:
`
M7 LightGBM Dynamic Rainfall Trigger Area (P>=0.60): 99.91% (Mean P: 0.9961)
`

This was investigated and root-caused to a proxy formula saturation issue.

### 6.2 Root Cause

The original soil moisture proxy formula:
`python
soil_moisture = (ndmi + 0.20) / 0.70 * 100   # OLD — saturated formula
`

For typical summer mountain forest (NDMI ≈ 0.52):
`
soil_moisture = (0.52 + 0.20) / 0.70 * 100 = 102.9%  →  clipped to 98.0%
`

Result: ~98% of scene pixels received soil_moisture ≈ 98%, pushing M7 LightGBM leaf values to extreme positive margins (P ≥ 0.999).

### 6.3 Fix Applied

`python
soil_moisture = (18.0 + np.clip((spectral.ndmi + 0.35) / 0.95, 0.0, 1.0) * 72.0).astype(np.float32)
`

| NDMI | Old Formula (%) | New Formula (%) | Physical Meaning |
|:-----|:----------------|:----------------|:-----------------|
| -0.35 | ~0% → clipped to 0 | 18.0% | Bedrock / dry bare rock |
| 0.00 | 28.6% | 44.5% | Dry season sparse grass |
| 0.25 | 64.3% | 63.2% | Moderate grass/shrub |
| 0.52 | 97.1% → saturated | 83.9% | Wet summer forest |
| 0.60 | 114.3% → clipped 98 | 90.0% | Saturated riparian vegetation |

**Key result**: New formula gives 83.9% for NDMI=0.52 vs 97%+ for old formula — preserving genuine variation between scenes.
