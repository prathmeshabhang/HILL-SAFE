## 3. Dataset Provenance Audit Findings

An exhaustive provenance audit was conducted comparing files in `data/validation_datasets/` against `data/external/`:

### Finding 1: `data/validation_datasets/` Generated Datasets
The datasets generated by `tools/validation/build_reference_datasets.py` in v3.8 were synthesized using statistical distributions (random Gaussian, Weibull, and empirical equations):
- `M6_stable_slope_controls.csv` (520 rows): Generated via `random.uniform`, `random.gauss`, and `fail_logit`. **PROVENANCE: SYNTHETIC**.
- `M7_storm_landslide_episodes.csv` (115 rows): Generated via `random.gauss` and `trigger_score`. **PROVENANCE: SYNTHETIC**.
- `M10_cwc_thalout_water_level.csv` (850 rows): Generated via `random.gauss` autoregressive stage drift. **PROVENANCE: SYNTHETIC**.
- `M11_satellite_flood_extents.json` (3 zones): Manual polygonal delineation. **PROVENANCE: PROXY_REFERENCE**.
- `M19_time_to_impact_events.csv` (55 rows): Generated via wave celerity equation with random noise. **PROVENANCE: SYNTHETIC**.
- `M20_damage_assessment_ground_truth.csv` (510 rows): Generated via Weibull variate and structural heuristics. **PROVENANCE: SYNTHETIC**.

### Finding 2: Genuine Real External Datasets in `data/external/`
Genuine external reference data already exists in `data/external/`:
- `data/external/m6/upper_beas/raw/kullu_upper_beas_landslides_2023_raw.csv`: **20 genuine GPS-verified landslide points** from GSI Report `M4EGG/C/NR/SU-PHP/2023/46620` and HPSDMA.
- `data/external/m6/upper_beas/raw/kullu_upper_beas_stable_controls_raw.csv`: **12 genuine negative control slope observations** (Naggar Castle, Bajaura Temple, Vashisht Bedrock).
- `data/external/events/himalayan_storm_landslide_catalog.csv`: **7 genuine storm episodes** (5 trigger events, 2 control non-trigger storms).
- `data/external/flood/raw/upper_beas_flood_events_2023_raw.csv`: **24 genuine field flood observations** (12 flooded points, 12 non-flooded controls) from HPSDMA, CWC, and NRSC.
